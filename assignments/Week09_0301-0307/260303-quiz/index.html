1. 큐 — 백준 10845 .js

[문제 설명]

정수를 저장하는 큐를 구현하고, 입력으로 주어지는 명령을 처리하는 프로그램을 작성하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/10845

[핵심 아이디어]

  • 배열로 큐 구현, head 포인터로 shift() 대신 O(1) 처리
  • push, pop, size, empty, front, back 명령 처리
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const N = parseInt(lines[0]);
  const queue = [];
  let head = 0;
  const result = [];

  for (let i = 1; i <= N; i++) {
    const [cmd, val] = lines[i].split(' ');

    if (cmd === 'push') {
      queue.push(parseInt(val));
    } else if (cmd === 'pop') {
      result.push(head === queue.length ? -1 : queue[head++]);
    } else if (cmd === 'size') {
      result.push(queue.length - head);
    } else if (cmd === 'empty') {
      result.push(head === queue.length ? 1 : 0);
    } else if (cmd === 'front') {
      result.push(head === queue.length ? -1 : queue[head]);
    } else if (cmd === 'back') {
      result.push(head === queue.length ? -1 : queue[queue.length - 1]);
    }
  }

  console.log(result.join('\n'));
});
2. 요세푸스 문제 — 백준 1158 .js

[문제 설명]

N명이 원형으로 앉아 있을 때, K번째 사람을 순서대로 제거하고 제거된 순서를 출력하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/1158

[핵심 아이디어]

  • 큐에 1~N을 넣고, K-1번 앞에서 빼서 뒤로 넣기를 반복
  • K번째 원소를 제거하고 결과에 추가
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });

rl.on('line', line => {
  const [N, K] = line.trim().split(' ').map(Number);
  const queue = [];
  const result = [];

  for (let i = 1; i <= N; i++) queue.push(i);

  while (queue.length) {
    // K-1번 앞에서 빼서 뒤로
    for (let i = 0; i < K - 1; i++) queue.push(queue.shift());
    result.push(queue.shift());
  }

  console.log('<' + result.join(', ') + '>');
  rl.close();
});
3. 카드2 — 백준 2164 .js

[문제 설명]

N장의 카드가 있을 때, 맨 위 카드를 버리고 그 다음 카드를 맨 아래로 옮기는 과정을 반복하여 마지막에 남는 카드를 출력하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/2164

[핵심 아이디어]

  • head 포인터로 shift() 대신 O(1) 처리로 시간초과 방지
  • 맨 위 카드는 head++, 다음 카드는 queue에 push 후 head++
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });

rl.on('line', line => {
  const N = parseInt(line.trim());
  const queue = [];
  let head = 0;

  for (let i = 1; i <= N; i++) queue.push(i);

  while (queue.length - head > 1) {
    head++; // 맨 위 카드 버리기
    queue.push(queue[head++]); // 다음 카드 맨 아래로
  }

  console.log(queue[queue.length - 1]);
  rl.close();
});
4. 프린터 — 프로그래머스 Level 2 .cpp

[문제 설명]

우선순위가 높은 문서가 대기 중이면 현재 문서를 뒤로 보낸다. 내가 요청한 문서가 몇 번째로 인쇄되는지 반환하시오.

[난이도]

Level 2

[링크]

https://school.programmers.co.kr/learn/courses/30/lessons/42587

[핵심 아이디어]

  • 큐에 {우선순위, 원래인덱스} 쌍으로 저장
  • 현재보다 높은 우선순위가 있으면 뒤로, 없으면 인쇄
  • 인쇄된 문서가 내 문서면 카운트 반환
C++
#include <string>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

int solution(vector<int> priorities, int location) {
  queue<pair<int,int>> q;
  for (int i = 0; i < priorities.size(); i++) {
    q.push({priorities[i], i});
  }

  int count = 0;
  while (!q.empty()) {
    auto [priority, idx] = q.front();
    q.pop();

    // 현재보다 높은 우선순위가 있으면 뒤로
    bool hasHigher = false;
    queue<pair<int,int>> temp = q;
    while (!temp.empty()) {
      if (temp.front().first > priority) { hasHigher = true; break; }
      temp.pop();
    }

    if (hasHigher) {
      q.push({priority, idx});
    } else {
      count++;
      if (idx == location) return count;
    }
  }
  return count;
}
