5. 숨바꼭질 — 백준 1697 .js

[문제 주소]

https://www.acmicpc.net/problem/1697

[풀이 과정]

1. 왜 BFS인가?: 수빈이가 이동하는 모든 경우의 수는 가중치가 1초로 동일하다. 따라서 '가장 먼저 동생의 위치에 도달하는 경로'가 곧 최단 시간이 되므로 BFS가 적합하다.

2. 상태 정의: 현재 위치를 노드로, (X-1, X+1, 2*X)를 간선으로 생각한다.

3. 중복 방지: 한 번 방문한 위치를 다시 방문하는 것은 이미 최단 거리가 아니므로 `visited` 배열을 사용하여 이미 확인한 좌표는 큐에 넣지 않는다.

4. 최적화: 동생의 위치가 수빈이보다 뒤에 있다면 오직 걷기(-1)로만 갈 수 있다는 예외를 고려하여 범위를 0~100,000으로 제한한다.

Node.js
const fs = require('fs');
const [N, K] = fs.readFileSync('/dev/stdin').toString().split(' ').map(Number);

const visited = new Array(100001).fill(0);
const queue = [[N, 0]];
visited[N] = 1;

let head = 0;
while (queue.length > head) {
    const [cur, time] = queue[head++];
    if (cur === K) {
        console.log(time);
        break;
    }
    for (let next of [cur - 1, cur + 1, cur * 2]) {
        if (next >= 0 && next <= 100000 && !visited[next]) {
            visited[next] = 1;
            queue.push([next, time + 1]);
        }
    }
}
6. 미로 탐색 — 백준 2178 .js

[문제 주소]

https://www.acmicpc.net/problem/2178

[풀이 과정]

1. 최단 경로 탐색: 격자판 미로에서 이동 횟수를 구하는 전형적인 최단 거리 문제. 한 칸씩 사방으로 뻗어나가는 BFS를 사용하여 처음 (N, M)에 도달하는 값을 찾는다.

2. 좌표 이동: 상, 하, 좌, 우 4방향을 나타내는 `dx`, `dy` 배열을 사용하여 반복문으로 다음 좌표를 계산한다.

3. 메모리 관리: 별도의 방문 배열을 만들 수도 있지만, 원본 미로 배열(`map`)에서 방문한 칸을 0(벽)으로 바꾸거나 거리를 누적 기록하면 메모리를 절약할 수 있다.

Node.js
const fs = require('fs');
const input = fs.readFileSync('/dev/stdin').toString().trim().split('\n');
const [N, M] = input[0].split(' ').map(Number);
const map = input.slice(1).map(line => line.split('').map(Number));

const dx = [-1, 1, 0, 0], dy = [0, 0, -1, 1];
const queue = [[0, 0, 1]];
map[0][0] = 0;

let head = 0;
while (queue.length > head) {
    const [x, y, dist] = queue[head++];
    if (x === N - 1 && y === M - 1) {
        console.log(dist);
        break;
    }
    for (let i = 0; i < 4; i++) {
        const nx = x + dx[i], ny = y + dy[i];
        if (nx >= 0 && nx < N && ny >= 0 && ny < M && map[nx][ny] === 1) {
            map[nx][ny] = 0;
            queue.push([nx, ny, dist + 1]);
        }
    }
}
7. 토마토 — 백준 7576 .js

[문제 주소]

https://www.acmicpc.net/problem/7576

[사고방식 및 풀이 과정]

1. 다중 시작점(Multi-source):'익은 토마토'가 여러 개일 수 있고, 이들이 동시에 주변으로 퍼져나간다는 점이다. 따라서 BFS 시작 전, 모든 익은 토마토의 위치를 먼저 큐에 삽입해야 한다.

2. 종료 조건 체크: 모든 토마토가 익었는지 확인하기 위해 BFS가 끝난 뒤 전체 판을 다시 검사하는 대신, 초기에 '안 익은 토마토'의 총 개수를 세어두고, 토마토가 익을 때마다 개수를 줄여나가는 방식이 효율적이다.

3. 날짜 계산: 큐에 `[x, y, date]` 형태로 날짜 정보를 함께 저장하여, 마지막 토마토가 익었을 때의 `date` 값이 곧 최소 날짜가 된다.

Node.js
const fs = require('fs');
const input = fs.readFileSync('/dev/stdin').toString().trim().split('\n');
const [M, N] = input[0].split(' ').map(Number);
const box = input.slice(1).map(line => line.split(' ').map(Number));

const queue = [];
let unripe = 0;
for (let i = 0; i < N; i++) {
    for (let j = 0; j < M; j++) {
        if (box[i][j] === 1) queue.push([i, j, 0]);
        else if (box[i][j] === 0) unripe++;
    }
}

const dx = [-1, 1, 0, 0], dy = [0, 0, -1, 1];
let head = 0, days = 0;

while (queue.length > head) {
    const [x, y, d] = queue[head++];
    days = d;
    for (let i = 0; i < 4; i++) {
        const nx = x + dx[i], ny = y + dy[i];
        if (nx >= 0 && nx < N && ny >= 0 && ny < M && box[nx][ny] === 0) {
            box[nx][ny] = 1;
            unripe--;
            queue.push([nx, ny, d + 1]);
        }
    }
}
console.log(unripe === 0 ? days : -1);
