1. 숫자 카드 — 백준 10815 .js

[문제 설명]

N개의 숫자 카드를 가지고 있을 때, M개의 정수가 숫자 카드 중에 있는지 판별하시오.

[난이도]

실버 5

[링크]

https://www.acmicpc.net/problem/10815

[핵심 아이디어]

  • Set에 N개의 카드를 저장
  • M개의 숫자를 has()로 O(1) 조회
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const cards = new Set(lines[1].split(' '));
  const queries = lines[3].split(' ');

  // Set으로 O(1) 조회
  console.log(queries.map(q => cards.has(q) ? 1 : 0).join(' '));
});
2. 문자열 집합 — 백준 14425 .js

[문제 설명]

N개의 문자열로 이루어진 집합 S가 주어질 때, M개의 문자열 중 집합 S에 포함된 문자열의 개수를 구하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/14425

[핵심 아이디어]

  • Set에 N개의 문자열 저장
  • M개의 문자열을 has()로 조회해 카운트
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const [N, M] = lines[0].split(' ').map(Number);
  const set = new Set();
  let count = 0;

  for (let i = 1; i <= N; i++) set.add(lines[i]);
  for (let i = N + 1; i <= N + M; i++) {
    if (set.has(lines[i])) count++;
  }

  console.log(count);
});
3. 완주하지 못한 선수 — 프로그래머스 Level 1 .cpp

[문제 설명]

마라톤에 참여한 선수 중 완주하지 못한 한 명의 선수를 찾아 반환하시오. 동명이인이 있을 수 있습니다.

[난이도]

Level 1

[링크]

https://school.programmers.co.kr/learn/courses/30/lessons/42576

[핵심 아이디어]

  • unordered_map으로 참가자 이름별 카운트 저장
  • 완주자 카운트 감소 후 카운트가 남은 선수 반환
C++
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

string solution(vector<string> participant, vector<string> completion) {
  unordered_map<string, int> map;

  // 참가자 카운트 증가
  for (const string& p : participant) {
    map[p]++;
  }

  // 완주자 카운트 감소
  for (const string& c : completion) {
    map[c]--;
  }

  // 카운트가 1 이상인 선수가 완주 못한 선수
  for (const auto& [name, cnt] : map) {
    if (cnt > 0) return name;
  }

  return "";
}
4. Two Sum — LeetCode Easy .cpp

[문제 설명]

정수 배열 nums와 정수 target이 주어질 때, 합이 target이 되는 두 수의 인덱스를 반환하시오.

[난이도]

Easy

[링크]

https://leetcode.com/problems/two-sum/

[핵심 아이디어]

  • unordered_map에 {값: 인덱스} 저장
  • 현재 값의 짝(target - nums[i])이 map에 있으면 정답 반환
  • O(n)으로 해결
C++
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
  vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> map;

    for (int i = 0; i < nums.size(); i++) {
      int complement = target - nums[i];

      // 짝이 map에 있으면 정답 반환
      if (map.count(complement)) {
        return {map[complement], i};
      }

      map[nums[i]] = i;
    }

    return {};
  }
};
