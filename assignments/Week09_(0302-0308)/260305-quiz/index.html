[문제 주소]

const fs = require('fs');
const input = fs.readFileSync('/dev/stdin').toString().trim().split('\n');
const nSet = new Set(input[1].split(' '));
const mQueries = input[3].split(' ');

const result = mQueries.map(q => nSet.has(q) ? 1 : 0);
console.log(result.join('\n'));
3. 숫자 카드 2 — 백준 10816 .js

[문제 주소]

https://www.acmicpc.net/problem/10816
Node.js
const fs = require('fs');
const input = fs.readFileSync('/dev/stdin').toString().trim().split('\n');
const cards = input[1].split(' ');
const queries = input[3].split(' ');
const map = new Map();

cards.forEach(c => map.set(c, (map.get(c) || 0) + 1));
const ans = queries.map(q => map.get(q) || 0);
console.log(ans.join(' '));
4. K번째 수 — 프로그래머스 .cpp

[문제 주소]

https://school.programmers.co.kr/learn/courses/30/lessons/42748
C++
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

vector<int> solution(vector<int> array, vector<vector<int>> commands) {
    vector<int> answer;

    for (int c = 0; c < commands.size(); c++) {
        int i = commands[c][0];
        int j = commands[c][1];
        int k = commands[c][2];

        vector<int> temp;
        for (int m = i - 1; m < j; m++) {
            temp.push_back(array[m]);
        }

        sort(temp.begin(), temp.end());
        answer.push_back(temp[k - 1]);
    }

    return answer;
}
