1. 문자열 뒤집기 — 백준 9093 단어 뒤집기 .js

[문제 설명]

문장이 주어졌을 때, 각 단어를 뒤집어 출력하는 프로그램을 작성하시오.

[입력]

첫째 줄에 테스트 케이스의 수 T가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있으며, 영어 단어들이 공백으로 구분되어 주어진다.

[출력]

각 테스트 케이스에 대해 단어를 뒤집어서 출력한다.

const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const T = parseInt(lines[0]);
  for (let i = 1; i <= T; i++) {
    // 각 단어를 split('')로 배열화 후 reverse().join('')으로 뒤집기
    console.log(
      lines[i].split(' ').map(w => w.split('').reverse().join('')).join(' ')
    );
  }
});
2. 팰린드롬 판별 — 백준 10988 팰린드롬인지 확인하기 .js

[문제 설명]

알파벳 소문자로만 이루어진 단어가 주어진다. 이때, 이 단어가 팰린드롬인지 아닌지 확인하는 프로그램을 작성하시오.

[입력]

첫째 줄에 단어가 주어진다. 단어의 길이는 1보다 크거나 같고, 100보다 작거나 같다.

[출력]

팰린드롬이면 1, 아니면 0을 출력한다.

const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });

rl.on('line', line => {
  const s = line.trim();
  // 뒤집은 문자열과 원본이 같으면 팰린드롬
  const reversed = s.split('').reverse().join('');
  console.log(s === reversed ? 1 : 0);
  rl.close();
});
3. 특정 문자 개수 세기 — 백준 10808 알파벳 개수 .js

[문제 설명]

알파벳 소문자로만 이루어진 단어 S가 주어진다. 각 알파벳이 단어에 몇 개가 포함되어 있는지 구하는 프로그램을 작성하시오.

[입력]

첫째 줄에 단어 S가 주어진다. 단어의 길이는 100을 넘지 않으며, 알파벳 소문자로만 이루어져 있다.

[출력]

단어에 포함되어 있는 a의 개수, b의 개수, ..., z의 개수를 공백으로 구분해서 출력한다. 

const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });

rl.on('line', line => {
  const s = line.trim();
  // a~z 26개 알파벳 카운트 배열
  const count = new Array(26).fill(0);
  for (const ch of s) {
    count[ch.charCodeAt(0) - 97]++;
  }
  console.log(count.join(' '));
  rl.close();
});
4. 문자열 압축 (RLE) — 백준 16634 Run-Length Encoding, Run! .js

[문제 설명]

Run-Length Encoding(RLE) 인코딩/디코딩 프로그램을 작성하시오. 첫 글자가 E이면 인코딩, D이면 디코딩한다.

[입력]

첫째 줄에 E 또는 D로 시작하고, 공백 후 메시지가 주어진다.

[출력]

E이면 인코딩 결과, D이면 디코딩 결과를 출력한다. 인코딩 시 모든 문자에 반복 횟수를 붙인다.

[예시]

입력 출력
E HHHeellloWooorrrrlld!! H3e2l3o1W1o3r4l2d1!2
D H3e2l3o1W1o3r4l2d1!2 HHHeellloWooorrrrlld!! 
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });

rl.on('line', line => {
  const mode = line[0];
  const msg = line.slice(2);

  if (mode === 'E') {
    let result = '';
    let i = 0;
    while (i < msg.length) {
      const ch = msg[i];
      let count = 0;
      // 연속된 같은 문자 카운트
      while (i < msg.length && msg[i] === ch) { count++; i++; }
      // 1번 등장해도 숫자 붙임
      result += ch + count;
    }
    console.log(result);
  } else {
    let result = '';
    // 문자, 숫자 쌍으로 반복 복원
    for (let i = 0; i < msg.length; i += 2) {
      result += msg[i].repeat(Number(msg[i + 1]));
    }
    console.log(result);
  }

  rl.close();
});
