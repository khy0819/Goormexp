1. 제로 — 백준 10773 .js

[문제 설명]

0이 나오면 가장 최근에 쓴 수를 지우고, 마지막에 남은 수들의 합을 구하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/10773

[핵심 아이디어]

  • 0이면 stack.pop(), 아니면 stack.push()
  • 마지막에 스택에 남은 수들의 합 출력
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const K = parseInt(lines[0]);
  const stack = [];

  for (let i = 1; i <= K; i++) {
    const n = parseInt(lines[i]);
    if (n === 0) stack.pop();
    else stack.push(n);
  }

  // 남은 수들의 합
  console.log(stack.reduce((a, b) => a + b, 0));
});
2. 괄호 — 백준 9012 .js

[문제 설명]

소괄호 ()만 있는 문자열이 올바른 괄호 문자열(VPS)인지 판별하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/9012

[핵심 아이디어]

  • 여는 괄호면 push, 닫는 괄호면 pop
  • pop할 때 스택이 비어있거나 마지막에 스택이 남으면 NO
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.trim()));
rl.on('close', () => {
  const T = parseInt(lines[0]);

  for (let i = 1; i <= T; i++) {
    const stack = [];
    let valid = true;

    for (const ch of lines[i]) {
      if (ch === '(') {
        stack.push(ch);
      } else {
        if (stack.length === 0) { valid = false; break; }
        stack.pop();
      }
    }

    console.log(valid && stack.length === 0 ? 'YES' : 'NO');
  }
});
3. 균형잡힌 세상 — 백준 4949 .js

[문제 설명]

소괄호 ()와 대괄호 [] 두 종류의 괄호가 섞인 문자열이 균형 잡혀 있는지 판별하시오.

[난이도]

실버 4

[링크]

https://www.acmicpc.net/problem/4949

[핵심 아이디어]

  • 여는 괄호면 push, 닫는 괄호면 스택 top과 짝이 맞는지 확인 후 pop
  • 짝이 맞지 않거나 스택이 비어있으면 no
  • 정확히 '.'만 있는 줄이 오면 종료, 각 줄 마지막 '.'은 제외하고 검사
JavaScript
const readline = require('readline');
const rl = readline.createInterface({ input: process.stdin });
const lines = [];

rl.on('line', line => lines.push(line.replace(/\r/g, '')));
rl.on('close', () => {
  for (const line of lines) {
    if (line === '.') break;

    const stack = [];
    let valid = true;
    // 마지막 '.' 제외하고 검사
    const str = line.slice(0, line.lastIndexOf('.'));

    for (const ch of str) {
      if (ch === '(' || ch === '[') {
        stack.push(ch);
      } else if (ch === ')') {
        if (stack.length === 0 || stack[stack.length - 1] !== '(') { valid = false; break; }
        stack.pop();
      } else if (ch === ']') {
        if (stack.length === 0 || stack[stack.length - 1] !== '[') { valid = false; break; }
        stack.pop();
      }
    }

    console.log(valid && stack.length === 0 ? 'yes' : 'no');
  }
});
4. 짝지어 제거하기 — 프로그래머스 Level 2 .cpp

[문제 설명]

알파벳 소문자로 이루어진 문자열에서 같은 알파벳이 두 개 붙어있는 짝을 찾아 제거하는 과정을 반복하여 빈 문자열이 되면 1, 아니면 0을 반환하시오.

[난이도]

Level 2

[링크]

https://school.programmers.co.kr/learn/courses/30/lessons/12973

[핵심 아이디어]

  • 스택 top과 현재 문자가 같으면 pop (짝 제거)
  • 다르면 push
  • 마지막에 스택이 비어있으면 1, 아니면 0 반환
C++
#include <iostream>
#include <string>
#include <stack>
using namespace std;

int solution(string s) {
  stack<char> st;

  for (const char ch : s) {
    // 스택 top과 현재 문자가 같으면 pop (짝 제거)
    if (!st.empty() && st.top() == ch) {
      st.pop();
    } else {
      st.push(ch);
    }
  }

  // 스택이 비어있으면 1, 아니면 0
  return st.empty() ? 1 : 0;
}
