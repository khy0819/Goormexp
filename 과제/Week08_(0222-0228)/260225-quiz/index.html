1. 배열 원소의 합 — 백준 11720 숫자의 합 .js

[문제 설명]

N개의 숫자가 공백 없이 쓰여있다. 이 숫자를 모두 합해서 출력하는 프로그램을 작성하시오.

[입력]

첫째 줄에 숫자의 개수 N (1 ≤ N ≤ 100)이 주어진다. 둘째 줄에 숫자 N개가 공백 없이 주어진다.

[출력]

입력으로 주어진 숫자 N개의 합을 출력한다.

const fs = require('fs');
const input = fs.readFileSync(0).toString().split('\n');

const N = Number(input[0]);
const numbers = input[1].split('').map(Number);

// reduce를 사용하여 모든 원소의 합 계산
const result = numbers.reduce((acc, cur) => acc + cur, 0);

console.log(result);
2. 구간 합 구하기 — 백준 11659 구간 합 구하기 4

[문제 설명]

수 N개가 주어졌을 때, i번째 수부터 j번째 수까지 합을 구하는 프로그램을 작성하시오.

[제한 사항]

  • 1 ≤ N ≤ 100,000
  • 1 ≤ M ≤ 100,000
  • 구간 i, j는 1 ≤ i ≤ j ≤ N
const fs = require('fs');
const input = fs.readFileSync(0).toString().split('\n');

const [N, M] = input[0].split(' ').map(Number);
const arr = input[1].split(' ').map(Number);

// Prefix Sum (누적 합) 배열 생성
const prefixSum = new Array(N + 1).fill(0);
for (let i = 0; i < N; i++) {
    prefixSum[i + 1] = prefixSum[i] + arr[i];
}

let answer = [];
for (let k = 2; k < M + 2; k++) {
    const [i, j] = input[k].split(' ').map(Number);
    // 구간 합 공식: P[j] - P[i-1]
    answer.push(prefixSum[j] - prefixSum[i - 1]);
}

console.log(answer.join('\n'));
3. 두 수의 합 (Two Sum) — 백준 3273 두 수의 합

[문제 설명]

n개의 서로 다른 정수로 이루어진 수열이 있다. ai + aj = x를 만족하는 (ai, aj) 쌍의 수를 구하는 프로그램을 작성하시오. (1 ≤ i < j ≤ n)

[제한 사항]

  • 1 ≤ n ≤ 100,000
  • 1 ≤ x ≤ 2,000,000
const fs = require('fs');
const input = fs.readFileSync(0).toString().split('\n');

const n = Number(input[0]);
const arr = input[1].split(' ').map(Number).sort((a, b) => a - b);
const x = Number(input[2]);

let left = 0;
let right = n - 1;
let count = 0;

// 투 포인터 알고리즘 활용
while (left < right) {
    const sum = arr[left] + arr[right];
    if (sum === x) {
        count++;
        left++;
        right--;
    } else if (sum < x) {
        left++;
    } else {
        right--;
    }
}

console.log(count);
4. 최빈값 찾기 — 백준 2592 대표값

[문제 설명]

10개의 자연수가 주어질 때, 이들의 평균과 최빈값을 구하는 프로그램을 작성하시오.

[입력 예시]

10, 40, 30, 60, 30, 20, 60, 30, 40, 50

[출력 예시]

37 (평균), 30 (최빈값)

const fs = require('fs');
const input = fs.readFileSync(0).toString().trim().split('\n').map(Number);

// 평균 계산
const avg = input.reduce((acc, cur) => acc + cur, 0) / 10;

// 최빈값 계산 (Map 객체 활용)
const counts = new Map();
let maxFreq = 0;
let mode = 0;

input.forEach(num => {
    const count = (counts.get(num) || 0) + 1;
    counts.set(num, count);
    if (count > maxFreq) {
        maxFreq = count;
        mode = num;
    }
});

console.log(avg);
console.log(mode);
