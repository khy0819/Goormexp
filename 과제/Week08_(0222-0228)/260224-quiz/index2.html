테이블 구조 (ITEM_INFO)
Column name Type Nullable
ITEM_ID INTEGER FALSE
ITEM_NAME VARCHAR(N) FALSE
RARITY INTEGER FALSE
PRICE INTEGER FALSE
문제
ITEM_INFO 테이블에서 희귀도가 'LEGEND'인 아이템들의 가격의 총합을 구하세요.
컬럼명은 'TOTAL_PRICE'로 지정합니다.
입출력 예
ITEM_ID ITEM_NAME RARITY PRICE
0 ITEM_A COMMON 10000
1 ITEM_B LEGEND 9000
2 ITEM_C LEGEND 11000
3 ITEM_D UNIQUE 10000
4 ITEM_E LEGEND 12000
기대 출력
TOTAL_PRICE
32000
※ LEGEND 아이템 ID: 1, 2, 4 → 9000 + 11000 + 12000 = 32000
풀이 쿼리 (MySQL)
SQL 
SELECT SUM(PRICE) AS TOTAL_PRICE
FROM   ITEM_INFO
WHERE  RARITY = 'LEGEND';

문제
가장 큰 물고기 10마리의 ID와 LENGTH를 출력하세요.
결과는 LENGTH 내림차순, 길이가 같으면 ID 오름차순으로 정렬합니다.
제한 사항
  • 가장 큰 물고기 10마리 중 길이가 10cm 이하인 경우는 없음
  • 결과 컬럼명: ID, LENGTH
입출력 예
ID FISH_TYPE LENGTH TIME
0 0 30 2021/12/04
1 0 50 2020/03/07
2 0 40 2020/03/07
3 1 20 2022/03/09
4 1 NULL 2022/04/08
5 2 13 2021/04/28
6 3 60 2021/07/27
7 0 55 2021/01/18
8 2 73 2020/01/28
9 3 73 2021/04/08
10 2 22 2020/06/28
11 2 17 2022/12/23
기대 출력
ID LENGTH
8 73
9 73
6 60
7 55
1 50
2 40
0 30
10 22
3 20
11 17
풀이 쿼리 (MySQL)
SQL 
SELECT ID, LENGTH
FROM   FISH_INFO
WHERE  LENGTH IS NOT NULL
ORDER BY LENGTH DESC, ID ASC
LIMIT 10;

문제
Python 스킬을 가진 개발자의 ID, EMAIL, FIRST_NAME, LAST_NAME을 조회하세요.
결과는 ID 오름차순으로 정렬합니다.
제한 사항
  • SKILL_1, SKILL_2, SKILL_3 중 하나라도 'Python'이면 해당 개발자 포함
  • 결과 컬럼: ID, EMAIL, FIRST_NAME, LAST_NAME
  • 결과 정렬: ID ASC
입출력 예
ID FIRST_NAME LAST_NAME EMAIL SKILL_1 SKILL_2 SKILL_3
D165 Jerami Edwards jerami_edwards@grepp.co Java JavaScript Python
D161 Carsen Garza carsen_garza@grepp.co React
D164 Kelly Grant kelly_grant@grepp.co C#
D163 Luka Cory luka_cory@grepp.co Node.js
D162 Cade Cunningham cade_cunningham@grepp.co Vue C++ Python
기대 출력
ID EMAIL FIRST_NAME LAST_NAME
D162 cade_cunningham@grepp.co Cade Cunningham
D165 jerami_edwards@grepp.co Jerami Edwards
풀이 쿼리 (MySQL)
SQL 
SELECT ID, EMAIL, FIRST_NAME, LAST_NAME
FROM   DEVELOPER_INFOS
WHERE  SKILL_1 = 'Python'
   OR SKILL_2 = 'Python'
   OR SKILL_3 = 'Python'
ORDER BY ID ASC;
문제 설명
정수 num이 짝수일 경우 "Even", 홀수일 경우 "Odd"를 반환하는 함수 solution을 완성하세요.
제한 사항
  • num은 int 범위의 정수
  • 0은 짝수로 처리
입출력 예
num return
3 "Odd"
4 "Even"
풀이 코드 (C)
C 
char* solution(int num) {
    char* answer;
    if (num % 2 == 0) {
        answer = (char*)malloc(5);  // "Even" + '\0'
        strcpy(answer, "Even");
    } else {
        answer = (char*)malloc(4);  // "Odd" + '\0'
        strcpy(answer, "Odd");
    }
    return answer;
}
문제 설명
표준 입력으로 두 정수 n과 m이 주어집니다. 가로 n, 세로 m인 직사각형 모양의 별(*)을 출력하세요.
제한 사항
  • n과 m은 각각 1000 이하인 자연수
입출력 예
입력 출력
5 3 *****
*****
*****
풀이 코드 (C)
C 
#include <stdio.h>

int main() {
    int n, m;
    scanf("%d %d", &n, &m);

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++)
            printf("*");
        printf("\n");
    }
    return 0;
}
